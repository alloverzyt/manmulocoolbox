# 满木工具箱 (LocalToolbox)

一个免费、纯本地运行的 Windows 桌面工具箱，内置 33 个实用工具，覆盖 PDF / 图片 / 文档 / 文件 / 二维码 / 媒体 / 数据转换七大分类。基于 PySide6 构建，绿色单文件，双击即用。

- 当前版本：**v1.3.9**
- 仓库：https://github.com/alloverzyt/manmulocoolbox
- 🛠️ 开发者请看 **[DEVELOPMENT.md](DEVELOPMENT.md)**（开发交接文档）

> 你的文件**只在你自己的电脑上处理，绝不会上传到任何服务器**。没有账号系统、没有广告、没有联网上传。

---

## 一、下载与安装

1. 打开本项目的 **Releases** 页面：https://github.com/alloverzyt/manmulocoolbox/releases
2. 下载最新版的 `满木工具箱_v版本号.exe`（例如 `满木工具箱_v1.3.9.exe`）
3. **无需安装**，双击即可运行（绿色单文件版）

### 杀毒软件提示怎么办？

由于程序未做数字签名，个别杀毒软件可能弹窗提醒。这是误报，请放心：

- 点击「更多信息」→「仍要运行」即可
- 也可将程序加入杀毒软件白名单

### 首次启动

- 首次双击启动会稍慢（程序在自解压），请耐心等待几秒
- 首次运行会弹出欢迎向导，自动检测运行环境，按提示操作即可

## 二、怎么用（三步上手）

1. **选工具**：在首页点击任意工具卡片（或直接把文件拖到窗口，程序会推荐匹配的工具）
2. **拖入文件**：把要处理的文件拖进虚线框（时间戳转换、颜色转换等工具不需要文件，直接填参数）
3. **点运行**：需要的话先调整下方选项（如输出格式、质量等），点「开始处理」，完成后进度面板会显示结果

### 处理结果在哪里？

- 默认输出到**原文件所在的文件夹**，也可在选项中自定义输出目录
- 每个任务完成后，输出文件的完整路径会显示在进度面板中

## 三、33 个工具一览

**通用体验**：深色/浅色主题一键切换、调色盘自定义主题色、任务异步处理不卡界面。

## 四、遇到「需要先安装依赖」提示怎么办？

部分工具依赖额外组件。选中工具时如果看到**红色警示条**，表示对应依赖尚未安装：

1. 进入**依赖管理页**（左侧导航）
2. 页面分三个标签页：
   - **核心依赖**：点「一键安装缺失的核心依赖」即可（联网自动安装）
   - **可选依赖**：个别工具的增强功能，按需点「安装」
   - **外部工具**：LibreOffice（文档转换类需要）和 FFmpeg（媒体类需要），点「下载」——程序会先检测各个下载源的速度，**列出可用源让你选择**，选一个点「开始下载」
3. 安装完成后回到工具页即可正常使用

> 下载失败或卡住？通常是网络问题，换一个下载源再试；或点「官网」手动下载。

## 五、主题与外观

- 窗口左下角三个按钮：**切换深色/浅色主题**、**主题设置（调色盘）**、**关于**
- 调色盘可以自定义主题色，工具箱整体配色随之变化

## 六、常见问题（FAQ）

**Q：双击没反应？**
首次启动需解压，等待 5~10 秒；若仍无反应，检查杀毒软件是否拦截了程序。

**Q：软件会收集我的数据吗？**
不会。所有处理都在本地完成，不上传任何文件，也没有账号系统。

**Q：处理大量文件很慢？**
工具箱支持批量拖放、逐个处理，视频压缩/PDF 转换等本身耗时较长，属正常现象。

**Q：配置文件在哪里？**
`%APPDATA%\LocalToolbox\app_config.json`（记录主题、首次运行状态等）。

**Q：怎么升级到新版本？**
直接到 Releases 页下载新版 EXE 替换即可，配置会保留。

**Q：遇到 bug 或想要新功能？**
到 https://github.com/alloverzyt/manmulocoolbox/issues 提交反馈，欢迎附上操作步骤截图。
